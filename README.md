# Kaiju-Sounds
A soundboard of classic Showa-era kaiju roars. Pick a monster, tap a button, and hear it roar.

Included kaiju:

Godzilla (Showa)

King Ghidorah (Showa)

King Kong (Showa)

Mothra (Showa)

Anguirus (Showa)

Rodan (Showa)
